### What changed in 0.2.78

This release adds Agent sessions, a searchable list of past agent conversations that picks any of them back up, brings more than 80 color themes with a live preview, opens files and folders dropped from Finder anywhere in the window, and copies text an agent wrapped across rows as the one line it was.

#### Agent sessions
- A new Agent sessions button next to Quick Chat lists past conversations of Claude Code, Codex, OpenCode, Gemini CLI and the other supported agents, newest first, on this Mac or your other devices.
- The list starts in the focused session's folder; switch to This repo or Everywhere, filter by time, agent or device, or search titles, folders, branches and IDs.
- Enter resumes a conversation in a new PzzaCode session in its own folder. Cmd+Enter types the resume command into the session you opened the list from, when it is at a shell prompt.
- Most agents reopen the exact conversation. For agents that can only continue their latest one, only the newest conversation of each folder can be resumed, and older ones are marked "Cannot resume".
- Agents connected to PzzaCode can list and resume past conversations too; resuming into an open session asks you first.

#### Themes
- Settings > Appearance has a searchable theme list: PzzaCode's own themes plus open-source schemes such as Dracula, Nord, Catppuccin, Gruvbox, Solarized and Tokyo Night, grouped Dark, Light and High contrast.
- Moving through the list previews each theme on the whole app, and closing it goes back to yours. Each option shows a small "Aa" sample over a strip of its colors.
- The code editor and change views use the theme's colors.
- The two existing themes are now called PzzaCode and PzzaCode Light, and your choice carries over.

#### Drag and drop from Finder
- On a terminal, files and folders paste their quoted paths. On another device's terminal, files are copied over first.
- Anywhere else, they open: one folder opens the new-session form, files open in the editor and several folders open as folder tiles.
- Nothing happens when you drop over a dialog.

#### Terminals
- Copying text a program wrapped across rows, such as a long command in an agent's reply, joins the rows back into one line, so a pasted command runs as one.
- A URL or path that wraps across rows is recognized more reliably when you click it.

#### Git
- The dot on the footer's Git branch is gone: with uncommitted changes the branch icon itself turns amber, and clicking it opens the changes.
