### What changed in 0.2.82

This release adds Power settings that keep agents running while the Mac would otherwise sleep, even with the lid closed, and gives the folder icon in the new-session form the same color as the icons beside it.

#### Power
- Settings > General > Power has a new Keep agents running switch. While PzzaCode is open, the Mac does not go to sleep, so agents in your sessions keep working; the display still turns off.
- By default it only holds on the power adapter. Also on battery keeps it going on battery too, and it stops by itself below 20% battery or in Low Power Mode. It also lets the Mac sleep if it gets too hot.
- With the lid closed: macOS sleeps on lid close no matter what apps ask, so PzzaCode can install a small helper for it. Choose Set up, then allow PzzaCode in the background in System Settings > Login Items. Closing the lid then locks the screen and turns it off while the Mac keeps running.
- Nothing outlives the app: quitting PzzaCode, or PzzaCode stopping for any reason, gives sleep back within a minute and a half at most. You can remove the helper any time in System Settings > Login Items.
- Agents connected to PzzaCode can read and change this setting; turning it on asks you first.

#### New session
- The folder icon in the new-session form and menu has the same color as the device and mode icons next to it, instead of the dimmer accent color.
