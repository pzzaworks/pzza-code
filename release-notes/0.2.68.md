### What changed in 0.2.68

- Full Disk Access now shows its real status in Settings > Permissions. On recent macOS versions the check looked for a file that no longer exists and always reported "Not checked yet".
- Allowing Full Disk Access opens the right System Settings pane and shows PzzaCode in Finder, so granting it is a single drag into the list. macOS offers no prompt for this permission.
- The setup wizard installs tmux with Homebrew when it is missing on this Mac, then starts local terminals. If the install fails, the reason and a Retry button are shown.
- The Allow buttons in the permissions list now show their icon.
