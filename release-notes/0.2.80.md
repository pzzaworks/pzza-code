### What changed in 0.2.80

Agent sessions is now a plain list for the whole app: a conversation always picks up in a new PzzaCode session in its own folder, and the footer shows only the keyboard shortcuts.

#### Agent sessions
- Resume here and its Cmd+Enter shortcut are gone, along with the warning about an agent already running in the tile. The list is no longer tied to the session it was opened from.
- The footer no longer has buttons or a mode picker. Enter or a double click resumes the selected conversation in a new PzzaCode session, in the mode last picked for that agent.
- The keyboard shortcuts now stay visible in narrow windows too.
