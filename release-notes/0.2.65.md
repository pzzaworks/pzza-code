### What changed in 0.2.65

- The divider between a terminal and its code editor can now be dragged to resize them, in both the side-by-side and stacked layouts. The file tree's width can be dragged too, and both sizes are remembered per window.
- The code editor now opens the moment you click it, instead of waiting for the terminal's current folder to be looked up first (which took seconds on remote devices).
- When the file tree cannot read a folder, it now says why.
