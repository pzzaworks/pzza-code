### What changed in 0.2.37

- Removed Device Pairing and Device Bridge, including their settings, native approvals, activity events, and tools. Standard SSH devices, terminal sessions, and port forwarding remain available.
- Fixed terminal attention notifications quoting input prompts and unrelated screen text. Bells stay quiet while their terminal has keyboard focus; background alerts and command failures remain available.
- Corrected command notification context when viewing terminal scrollback.
- Added token totals and daily usage details for accounts on remote devices.
- Removed the duplicate forwarding route label and excluded SSH tunnel listeners from the local service list.
