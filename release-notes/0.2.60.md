### What changed in 0.2.60

- Agent usage now shows every account signed in on any connected device: all devices are queried together and each account keeps its freshest sample, so an account whose token lapsed on one machine is covered by another. A lapsed token shows the last known usage as stale instead of the card disappearing, and reopening the panel shows the last cards instantly.
- Adding the PzzaCode MCP server is idempotent for every agent CLI: an existing Claude entry with the same path is left alone, a moved app replaces the stale entry instead of failing with "already exists", and a CLI outside the app's PATH is found in its usual install locations or reported as not installed.
- Notification cards and desktop alerts preview long bodies up to 280 characters with an ellipsis, while history keeps the full text.
- Claude, Codex and OpenCode are detected in terminals on remote devices: remote tmux commands force UTF-8 so tab-separated listings parse without a locale, and npm-installed agents that retitle their process are recognized on Linux.
