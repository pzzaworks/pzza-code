### What changed in 0.2.50

- The tile status dot is grey normally and solid green only while the tile has unread notifications. Viewing the tile or opening its notification marks them read and clears the workspace tab dot when nothing else is unread there.
- The tile close dialog now only terminates; use Hide to keep a session running out of sight.
- Automatic grid tiles match the tallest explicit height in the workspace and fill rows without holes.
- Right-click is contextual now: workspace tabs open their settings, tile headers open the layout menu, and empty areas no longer show a lone Copy item.
- Context menus size to their content, and terminal Select all disables when everything is already selected.
