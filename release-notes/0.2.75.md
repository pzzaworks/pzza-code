### What changed in 0.2.75

This release brings your agents back the way you started them after a refresh, keeps Quick Chat working through terminal restarts, and makes dictation hold on to your words in noisy rooms.

#### Sessions come back as you started them
- Refresh sessions and restored sessions resume each agent the way it was running: in the same permission mode and with the same account folder. An agent you start through a shell function, such as one that sets `CLAUDE_CONFIG_DIR` for a second Claude Code account, continues in that account instead of the default one.
- An agent running with an account folder PzzaCode cannot pass back is left at its shell rather than resumed on the default account, which holds other logins and conversations.
- Two agents in the same folder that use different accounts each continue their own conversation.

#### Quick Chat
- Quick Chat opens with the Claude Code account your sessions on that device use, still in the mode that asks before changes.
- A chat that ended, for example after Refresh sessions restarted the terminal server, is replaced by a new one instead of staying on "Retry attachment". If it ended while Quick Chat was hidden, the new one starts the next time you open it.

#### Dictation
- Stopping no longer drops the words the preview showed when the final pass reads only noise ("Thank you."); those words are typed instead.
- With steady background noise such as a fan, the last word of a sentence is typed as soon as you pause, instead of waiting for Stop while the recording drifted into made-up words.

#### Look and feel
- On narrow windows, a tool's dropdown opened from the collapsed toolbar menu now opens below the menu with a gap instead of touching its edge.
