### What changed in 0.2.45

- Session grid auto layout stretches the last session across the leftover columns, so the final row never leaves an empty gap.
- Right-click menus match the top-bar dropdown padding and every label has its own icon.
- Notification titles render the device part like the rest of the title.
- Changing the Quick Chat device or agent now closes the old conversation and opens the new profile instead of sticking to the previous session.
