### What changed in 0.2.84

This release makes renaming a session rename it for real, keeps tile sizes per workspace, and resumes Claude Code conversations whose folder was moved.

#### Renaming sessions
- Renaming a session tile now renames its tmux session (or window) on the device. It gets exactly the name you typed, the footer shows it, and the old name is free again for a new session.
- Other windows and devices that still show the session under its old name follow it to the new name, instead of starting an empty session with the old one.
- The session's editors are read-only for the moment the rename takes, so nothing you type in them is lost.
- Names PzzaCode keeps for its own sessions are refused with a clear message.
- Agents connected to PzzaCode rename tiles the same way.

#### Tile sizes
- Sizes are kept per workspace. Resizing a tile in All no longer makes it fill the screen in its own workspace. Sizes from earlier versions stay in All, so your other workspaces start with automatic sizes once.
- Auto arrange and deleting a workspace only change that workspace's sizes.
- The grid no longer slides sideways, leaving an empty strip on the right, after tiles move.
- Moving to a tile taller than the window scrolls to its top, so its header stays in view.
- Restoring a workspace snapshot hides the right remote and window tiles again.

#### Agent sessions
- A Claude Code conversation whose folder was moved or deleted resumes again, in the folder it last worked in (or your home folder), instead of failing with "Choose an existing absolute working directory".
