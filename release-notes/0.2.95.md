### What changed in 0.2.95

This release rebuilds Help on the same pages as the website docs, adds a Guides section, makes a notification click open what it is about, and stops Git protection from flagging content the destination already has.

#### Help
- Help now shows the same pages as the docs on the website, with the same scenes drawn from the app's own interface, sized for the Help window.
- A new Guides section walks through PzzaCode features end to end. It is also in the Help menu and the command palette.

#### Notifications
- Clicking a notification opens its related activity, the same as Open related activity, and closes the panel. A notification without a target opens its details.

#### Git protection
- A push no longer re-checks files the destination's default branch already holds, so content that is already published does not block it. New content is scanned exactly as before.
