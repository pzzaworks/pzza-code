### What changed in 0.2.91

This release brings a Port manager that tells you what every port is, tiles that keep their size when you resize one of them, Command + number to jump between tiles on macOS, and a round of security hardening.

#### Port manager
- Each port now says what it runs (Next.js, NestJS, PostgreSQL and other well-known services), next to the project it belongs to.
- You can see which session started it, how long it has been up, and whether it is open to the network or to this device only. The list also counts how many ports are open to the network.
- A filter appears on long lists: search by name, port, session or kind of service.

#### Tiles
- Resizing a tile no longer shrinks every other tile to keep them all on screen. Rows keep their height; tiles that no longer fit move below and the canvas scrolls to them.
- A tile is never taller than the window, even with a size it was given while more tiles shared the canvas.
- On macOS, tiles are selected with ⌘1 to ⌘9 instead of ⌃1 to ⌃9, which leaves Control to the shell. Other platforms keep Ctrl + number.

#### Permissions
- Automation no longer falls back to "Not checked" after it was allowed. PzzaCode now starts System Events before reading the permission, which is what macOS needs to answer.

#### Look
- The headers that stay in place while you scroll the Worktrees, Agent sessions and Checkpoints dialogs and long dropdowns have rounded corners over glass.
- The Restart and Refresh sessions buttons beside the version are easier to see.

#### Security
- Every SSH connection requires a known host key, including file, git, search, project and remote desktop features that used to accept a new key on first contact.
- Device hosts are validated before they reach ssh, so a host name can no longer be read as an ssh option.
- The remote desktop password is no longer visible in the local process list while it is saved to the Keychain.
- ⌘-clicking an app bundle path reveals it in Finder instead of launching it, and links in a Markdown preview open in the browser.
