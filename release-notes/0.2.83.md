### What changed in 0.2.83

This release fixes setting up Power's lid-closed mode in 0.2.82, where the Set up button never appeared.

#### Power
- Settings > General > Power shows Set up under With the lid closed again. In 0.2.82 PzzaCode mistook a helper that had not been set up yet for one missing from the app, so it hid the button and the lid-closed mode could not be turned on.
- If macOS cannot install the helper, Set up now says why.
