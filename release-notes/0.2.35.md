### What's new in 0.2.35

This update finishes OpenCode Go support, makes usage cards honest, and smooths out sync, bridge, find, and Help.

**OpenCode Go, done right**

- The usage card is branded Go (not Zen) and matches the CLI: the rolling window feeds the familiar 5h bar, weekly and monthly follow, and the duplicate Rolling row is gone.
- Spend is real billed cost from the local OpenCode session database - Today, Yesterday, Last 30 days, token trend, and daily breakdown all fill in instead of showing zeros. The note reads "Billed spend, not an estimate."
- Terminals running opencode are recognized everywhere, including older sessions that only left a pane label behind.
- The OpenCode icon is now the official brand mark from opencode.ai, with light and dark variants that follow the app theme.

**Usage cards show brand logos**

- The colored dots are gone; each card leads with its Claude, Codex, or OpenCode logo in its brand color.

**One-click sync and bridge fixes**

- Clone-blocked projects (a folder belonging to another project, or two projects wanting the same path) get an Exclude project button, so the rest of sync proceeds. Nothing is overwritten; re-enable from the row switch anytime.
- Bridge project IDs are suggested from the chosen folder, and the redundant SSH alias box only appears when no devices are configured.

**Find that stays out of the way**

- The terminal find bar is fully opaque in both appearances, and Cmd/Ctrl+F inside the code editor opens the editor's own find instead of the browser's.

**Help and tour polish**

- Every Help subpage has its sidebar icon, and the onboarding tooltip has breathing room so its actions never clip.
