### What changed in 0.2.72

#### Tasks
- Tasks opens from the top bar as a dropdown built like Notifications and New session, so the canvas never moves. Tasks are grouped into Needs you, Working, Review and Done; empty groups are hidden and Done starts folded.
- A new task starts from its prompt: the repository, base branch and agents are remembered, the title comes from the prompt, and Cmd+Enter starts it. Every task works in its own worktree on a new `pzza/` branch.
- Four modes: One (a single agent), Parallel (one task per line, all started at once), Chain (steps on the same branch, one after another: write, then review, then fix, or plan, then build) and Race (the same prompt to up to four agents, keep the best). A chain step that needs you pauses the chain; resume, skip the step or stop it.
- The dropdown keeps the quick part: status, the changes at a glance and the next step (Commit, Land or Open pull request). Open details shows the whole task in a window like Checkpoints: its attempts or steps, each one's changes and diff, every land check and every action.
- Land checks (agent idle, nothing waiting for approval, clean worktree, check command) offer the fix for the first one that fails.
- A task launch that is interrupted or fails cleans up the worktree and branch it created. Anything with your changes or commits in it is kept and offered for discard instead.
- Every way to land a worktree goes through the same checks. Merge or Open pull request on a task's worktree, from the tile or from the workspace settings, opens that task's Land, so its outcome is recorded. Other worktrees are checked for a busy agent, a waiting approval and uncommitted changes first.

#### Approvals
- Approval prompts are answered from the notification, for tiles that are hidden, in another workspace, or waiting at the same time as others. A tile on screen no longer gets a bar over its terminal: its prompt is right there, and the tile shows it is waiting.
- Answering from the app now covers 19 more agents, among them Gemini CLI, Cursor Agent, GitHub Copilot CLI, Antigravity, Qwen Code, Kiro, Factory Droid, Crush, Kilo Code, goose, Cline and Aider. Each one is answered with its own keys; Esc is never used to decline where it does something else.
- A long command whose start scrolled off the tile can still be declined from the app, and approved once its full text is read back from the terminal's history.

#### Notifications
- A hidden tile running an agent lights up when the agent stops and may need you, not while it is still working.
- Things you just did in plain view no longer notify: a session opened, a device added or removed, a task started, a worktree set up, or a sync finished while its menu is open. Failures still do.
- The remote desktop button brings an open desktop to the front, and opens its settings when no server is set.
- Refreshing sessions shows its message only when none of the refreshed tiles is on screen, or when it fails.
- Clearing finished tasks, deleting a saved prompt and clearing notification history no longer ask first. Opening a pull request or merging from a tile shows success in place instead of a dialog.
- The Terminal command result event is gone: terminals run inside tmux, which never passes that signal on.

#### Checkpoints
- Every agent turn is saved, also in tiles that are not focused or not on screen, and named after the agent's own summary. Restarting the app no longer cuts a turn in two.
- Changes made between turns are shown as such instead of under the next turn's baseline.
- One checkpoints button per tile, in its status bar. It shows in every Git folder, also before the first checkpoint, so one can be saved by hand.

#### Setup
- Setup installs what PzzaCode runs on before asking for permissions, so tmux exists when its permissions are granted. Until then the tmux permissions wait instead of failing.
- Running setup again from Settings no longer replays the tour.
- Semi-transparent mode keeps text visibility, background opacity and desktop blur in view; the finer controls sit under More transparency controls.
- Continue and Worktree in New session show as filled when on, without a ring.

#### Broadcast
- Selecting two or more tiles slides a composer up from the bottom of the canvas, with a blur that deepens toward the edge. It reads like the command palette: the selected sessions as chips on top, and below them one field with saved prompts, dictation and Send.
- All agents adds every tile running a coding agent. Messages can span several lines (Shift+Enter) and skip sessions waiting on an approval prompt.
- The command palette has Broadcast to every agent.

#### Top bar
- New session is a single bordered + button, and the tools are grouped by thin dividers, so more of them stay visible.
- Grid columns moved from their own button into each workspace's menu: click the workspace tab and pick Auto, 2, 3 or 4 under Layout. The command palette still sets them too.

#### Agents
- Real logos for every agent but Aider.
- Each agent starts in a mode that asks first: Codex, Cursor and Aider now really ask, and OpenCode and Kilo cannot be switched to running everything by your own settings. Cursor needs its January 2026 CLI or later for this.
- Factory Droid no longer offers a skip-permissions mode its terminal app ignores, and resumes the last session in the folder instead of opening a picker.
- Quick Chat warns when the chosen agent has no mode that asks first, such as Amp.
- A starting prompt with `!` works in tcsh and csh login shells too.

#### Usage
- Usage, cost and model for eight more agents under Other agents, read from their own local session data.
- The usage details have more room between the trend, the daily breakdown and the totals.

#### Performance and reliability
- Sessions just outside the view stay connected and the ones further away reconnect before they scroll in, so scrolling the canvas no longer stutters while tiles reload.
- The bundled device agent is checked to start before a release ships, so the app can no longer open on "Agent unreachable" because of a missing file.
- Text fields grow with what you type instead of clipping their second line, and folder pickers open on a deep folder instead of failing to find it.
- Every dropdown shares the Port manager's header and spacing.
- Borders of floating panels stay visible in semi-transparent mode.
