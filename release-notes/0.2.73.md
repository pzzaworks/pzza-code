### What changed in 0.2.73

This release is about keeping your terminals safe. In 0.2.72, a permission read as newly granted (which an update could cause) restarted every local terminal on its own, and if the app went down during that restart, sessions were lost. That can no longer happen.

#### Your sessions stay put
- PzzaCode never restarts the terminal server on its own. A newly allowed permission sends a notification instead: new terminals have it right away, and running sessions get it only when you choose Refresh sessions, which now asks first and says what stops.
- A refresh writes down every session, its windows, folders, output and agents before anything restarts. If the app quits, crashes or loses power in the middle, the next launch brings every session back, with its output.
- A session that cannot be restored is never forgotten: it is retried on the next launch instead of being dropped.
- The terminal server no longer ends when its background helper exits or is replaced (for terminal servers started by this version). A helper that starts while terminals are running takes over looking after them.
- Two copies of PzzaCode can no longer run at once and overwrite each other's sessions and settings: opening a second copy brings the first one to the front.
- Quitting, restarting and updating wait for a running refresh or restore to finish.
- When the terminal server cannot start, PzzaCode keeps trying in the background instead of staying without terminals until a relaunch.
- Restoring a folder with several agent sessions continues the last conversation in one of them, instead of opening the same conversation in all of them.

#### Nothing typed where it should not be
- Broadcasts, saved prompts, task chains and dictation check for an approval prompt right before pressing Enter, so they never answer one by accident.
- A task chain pauses when the agent of a step has exited, instead of typing its next instruction into the shell.
- Keys the app sends, such as Reject on an approval prompt, always arrive, even right after you scrolled.
- Ending a session or syncing projects from an agent tool asks you first in the app.
- Terminating a window tile ends exactly that window, never another one that took its number.

#### Files and Git
- Saving a file is atomic, locally and on remote devices: a dropped connection or a full disk never leaves it half written.
- The editor asks before saving over changes an agent made to the file after you opened it, and opens files that are not UTF-8 text read-only instead of corrupting them.
- Project Sync skips local branches with commits that are not on origin, and checkouts where a session is working or that have uncommitted changes.
- Discarding a task lists the ignored files it would delete.
- Git protection keeps working after a Node.js upgrade, and tells you how to repair it if Node.js is gone.

#### Steadier app
- A part of the window that fails shows a calm message with Try again, and the rest of the app keeps working.
- Saved settings from older versions or damaged ones are repaired on load instead of stopping the app from opening. The Main workspace cannot be deleted.
- Saved-by-hand workspace snapshots are never pushed out by auto-saves.
- The window opens right away, even when a shell profile is slow.
- PzzaCode no longer cancels a macOS logout, restart or shutdown.
- Updates that need an administrator password are not retried in the background: you are told once and can install by hand.
- On Linux devices set up or added again with this version, restarting the device agent no longer ends their terminals.
