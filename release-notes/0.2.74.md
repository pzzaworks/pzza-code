### What changed in 0.2.74

This release makes PzzaCode much lighter on your Mac, turns its editor into one you can open any code file with, and fixes a long list of rough edges in terminals, dictation and the semi-transparent look.

#### Lighter and cooler
- Idle PzzaCode uses a fraction of the CPU, threads and memory it did: background helpers sleep until there is work instead of polling, and nothing is started on a timer.
- In semi-transparent mode the glass behind a terminal is refreshed only on the frames the terminal actually redraws, instead of every frame while an agent works. This was the main cause of a warm Mac with agents running.
- The voice model frees its memory after five minutes without dictation and loads again on the next use.

#### Open code files with PzzaCode
- Open any code or text file from Finder with PzzaCode, or use File > Open File… (Cmd+O) and Open Folder… (Option+Cmd+O). Files open in their own editor tile, without starting a terminal; opening one again brings its tile forward.
- Open terminal here turns a file or folder tile into a session in its folder, right where it is, with the editor beside the terminal.
- Make PzzaCode the default editor for the file types you choose, in the last setup step or in Settings > Setup. Web pages are never included, so your browser stays the default.

#### A better editor
- Go to file (Cmd+P), search the folder (Cmd+Shift+F inside an editor) and go to symbol (Cmd+Shift+O).
- Select code to Explain it, Fix it or Send it to the tile's agent (Cmd+L), with the file and lines included. Nothing is sent while an approval prompt is waiting.
- Changed lines are marked in the gutter; click a mark to see the old lines or revert them. The line you are on shows who changed it last and when.
- Jumping to a line in another file, from a search result or go to definition, lands on the right line.
- Files you cannot open here say why, instead of showing "invalid path".

#### Terminals
- Cursor blink now works in every terminal.
- Terminal text no longer stretches while a window, a tile or the editor split is resized.
- A terminal that was resized while it was connecting now gets the right size instead of staying small.
- Resizing a tile applies at once, also when it is the only tile in the workspace.

#### Dictation
- Every word shown in the preview is typed when you release the key; the final pass can correct words but no longer drops them.
- Words are typed during short pauses instead of waiting for the end of the recording.

#### Look and feel
- Every menu, dialog and bar follows semi-transparent mode, and the desktop blur behind the window stays on after switching Spaces, displays or apps.
- Dark mode is easier to read: secondary text, field and button edges, dividers and the usage meter all stand out more.
- Workspace icons show in Move to workspace, and file actions have their icons back.

#### Git protection
- Repositories that were moved, or protected by an older version, have their hooks repaired at launch, and a moved repository stays protected. Protection is never turned on for a repository you did not choose.
