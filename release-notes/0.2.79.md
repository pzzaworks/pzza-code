### What changed in 0.2.79

This release keeps every dropdown list fully on screen and moves Agent sessions to the second place in the top bar.

#### Dropdowns
- A list opened near the bottom of the window, such as the agent mode picker in Agent sessions, now opens upward when there is more room above, instead of running past the window edge.
- A list is never taller than the room it opens into, so its last options can always be scrolled to.

#### Top bar
- Agent sessions now sits right after Tasks, with Quick Chat after it.
