### What changed in 0.2.87

This release makes refreshed sessions continue their own Claude Code conversations, stops updates from interrupting running agents, and shows worktrees for folders of projects.

#### Refreshing sessions
- Claude Code sessions continue exactly the conversation they were in, even when several sessions share a folder. Before, a refreshed session reopened the newest conversation in its folder, which could be another session's.
- A session whose conversation is not known reopens the newest one only when no other Claude Code session works in that folder; otherwise it stays at the shell and the notice names it.
- After an update, terminals no longer restart on their own while work runs. They move to the new version once every agent is idle and nothing else runs in them, and a notification says they are waiting. Refresh sessions in Settings > Setup still moves them right away, and its confirmation names the sessions where something is running.

#### Worktrees
- A session working in a folder of projects (not a repository itself) shows the worktrees of every repository directly inside that folder in workspace settings, each repository once.
