### What changed in 0.2.38

- Fixed remote desktop windows closing immediately when the server is locked. Connections now use configured Remote Login when available, preserving the existing account and screen lock.
- Fixed normal Quit hanging when terminal output was still buffered after the window closed.
- Closing PzzaCode now closes remote desktop viewers and their SSH connections, including requests still starting. Canceling Quit keeps the connection open; terminal sessions continue running.
- Replaced raw connection logs in notifications with short, actionable errors.
- Protected viewer credentials from process listings and verified Remote Login certificates through the SSH connection.
- Preserved significant spaces in saved remote login credentials.
- Kept port manager project names visible when another listening process exits during a scan.
