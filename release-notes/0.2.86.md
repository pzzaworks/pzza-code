### What changed in 0.2.86

This release makes Worktrees in workspace settings find the repositories your sessions work in.

#### Worktrees
- Worktrees now reads the folder each session is in right now. Before, it read the folder the session was opened in, so a session started in a parent folder that later moved into a repository showed "No extra worktrees" even when the repository had many.
- A worktree a session moved into later counts as in use, so it is no longer offered for removal.
