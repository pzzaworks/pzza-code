### What changed in 0.2.67

- Links that wrap onto two or three lines now open in full with Cmd-click, from any of their lines. Before, tmux and agent output split long URLs into separate rows, so only the first part opened.
- Double-clicking a wrapped link selects the whole link and copies it as one URL, without the line breaks in between.
- Setup now asks for the macOS permissions your terminals need: Full Disk Access, Microphone, Screen Recording, Accessibility and Automation. Terminals and their tmux server run as PzzaCode, so these grants cover every shell, agent and tool you start in the app. Skipped ones stay available in Settings > Permissions, which shows the live status of each and opens the right System Settings pane.
- Scripts in terminals can now ask for Automation access (for example `osascript` controlling System Events) instead of being refused without a prompt.
- New Grayscale mode in Settings > Appearance turns the tinted interface neutral gray. Status colors and the colors programs print in the terminal stay as they are.
