### What's new in 0.2.34

This update adds OpenCode to Quick Chat, finishes OpenCode usage, repairs tokens in one click, finds text anywhere, opens Help as readable articles, and walks new users through the app.

**OpenCode as a Quick Chat profile**

- Quick Chat profiles now include OpenCode alongside Claude and Codex, with the same managed conversation, hiding, and reattachment behavior.
- The opencode CLI launches directly, falling back to its well-known install locations when it is outside PATH.

**OpenCode Zen usage that actually loads**

- Zen usage combines the credits quota with rolling, weekly, and monthly windows, so pay-as-you-go workspaces see real percentages instead of empty cards.
- The panel keeps its device fallback: the app's device first, then connected devices.

**One-click usage repairs**

- An expired Claude token shows a Run Claude to refresh action that runs the CLI once to refresh it, then reloads usage.
- Credential and environment files are no longer withheld from editor control.

**Find in terminal and editor**

- Cmd/Ctrl+F in any terminal opens a floating find bar with highlight-all matches, a match counter, case toggle, and Enter/Shift+Enter navigation.
- The code editor gains the standard find panel plus selection-match highlights, themed to match.

**Help as articles plus a guided tour**

- Help topics read as flowing articles with a tour banner up top - no cards, no accordions, no decorative icon tiles.
- Fresh installs get a nine-step spotlight walkthrough after the setup wizard, replayable anytime from Help.
- The New Session form is narrower and the empty workspace card fills more of the canvas.
