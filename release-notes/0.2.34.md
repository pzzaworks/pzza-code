### What's new in 0.2.34

This update brings OpenCode everywhere it belongs, makes usage errors fixable in one click, refreshes Help, and walks new users through the app.

**OpenCode as a Quick Chat profile**

- Quick Chat profiles now include OpenCode alongside Claude and Codex, with the same managed conversation, hiding, and reattachment behavior.
- The opencode CLI launches directly, falling back to its well-known install locations when it is outside PATH.

**OpenCode Zen usage that actually loads**

- Zen usage combines the credits quota with rolling, weekly, and monthly windows, so pay-as-you-go workspaces see their numbers instead of an empty card.
- The panel keeps its device fallback: the app's device first, then connected devices.

**One-click usage repairs**

- An expired Claude token shows a Run Claude to refresh action that runs the CLI once to refresh it, then reloads usage.
- The same flow is available to automation through the new usage repair endpoint.

**Help rewritten and a Code editor topic**

- Stale control sets, shortcuts, and integration lists now match the app: real tile actions, all six MCP clients with Add, OpenCode usage, and the token fix.
- New Code editor topic covers the built-in editor, its layouts, and Cmd/Ctrl/Alt+Click go-to-definition.
- Topic rows brighten on hover and emphasize the open section.

**First-run guided tour**

- Fresh installs get a nine-step spotlight walkthrough after the setup wizard: workspaces, tools, tiles, and settings, one control at a time.
- Anchors that are not visible are skipped gracefully, and the tour replays anytime from Settings → Help → Tips.

**Tighter New Session form**

- The New Session dropdown is narrower with compact rows, matching the other menus, and the empty workspace card fills more of the canvas.
