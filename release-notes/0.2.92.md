### What changed in 0.2.92

This release turns Refresh sessions into a dialog where you choose what to refresh, brings agents and programs back exactly the way you started them, gives the Port manager a calmer, compact design, and makes "agent finished" notices say what the agent actually said.

#### Refresh sessions
- Refresh sessions opens a dialog listing this Mac's sessions, grouped by the workspace their tile is on. Refresh all of them, or only the ones you pick.
- Refreshing chosen sessions restarts them in place: the other sessions keep running, and attached tiles stay attached. Refresh all still restarts the terminal server, so newly granted permissions reach every terminal.
- Agents come back through the same shell alias or function you started them with, read from your own shell, so flags the app does not know about are kept. A `claude --chrome` you start through an alias resumes through that alias, still with `--chrome`.
- Programs other than agents can start again too. Each one is listed under its session; dev servers that listen on a port are ticked by default, everything else is your choice. A program is typed again only when its pane still runs exactly what the dialog showed, and pipelines, `sudo`, nested shells and programs that renamed themselves are never typed again.

#### Port manager
- Compact rows grouped by the session that started each port, with filter chips for sessions, network and containers.
- System services, coding agents' own helper ports and PzzaCode's internal sessions are hidden until you show them.
- A port appears once however many addresses or sockets it holds, and a server started from a background job still shows under its session.
- Calmer colors: no more yellow, and the stop button is the only control that turns red.

#### Notifications
- A notice for an agent that finished while its tile was hidden now quotes the agent's last message, and says when it is asking you something.
- Agents that only compact or summarize while idle no longer send a notice.

#### Look
- The buttons in the new session menu have a quiet hover that fills the whole cell, without the thick border Worktree and Continue used to get.
