### What changed in 0.2.85

This release stops resized tiles from growing past the window.

#### Tile sizes
- Tiles with a size you set always fit the window together. Before, widening one of two tiles side by side moved the other to a new row and made both rows a full window tall, and a size set while more tiles shared the canvas grew taller once a session closed or was hidden. This happened in every workspace, All included.
- Making a tile shorter still leaves the room below it free.
