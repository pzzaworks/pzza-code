### What changed in 0.2.62

- Devices can be disabled in Settings → Devices. A disabled device stays configured but leaves every device picker, agent usage, sync, MCP checks, port forwarding, remote desktop and the canvas until it is enabled again. Quick Chat, forwarding and remote desktop choices that pointed at it fall back automatically.
- Sync, remote desktop and the port manager's Forwarded tab only appear when an enabled remote device exists.
- Agent usage no longer shows a red "fetch failed" card when a device cannot reach the usage service.
