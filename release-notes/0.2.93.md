### What changed in 0.2.93

This release makes updates land on the latest version even when several releases came out before you restarted.

#### Updates
- An update that is installed and waiting for its restart no longer stops PzzaCode from looking for newer ones. When a newer release comes out first, it is installed in its place, so Restart to update takes you straight to the latest version instead of one version at a time.
- Restart to update stays in the top bar while PzzaCode looks, and the waiting update is kept when the check fails.
- With automatic updates off, Update offers the newest version instead of restarting into an older one.
